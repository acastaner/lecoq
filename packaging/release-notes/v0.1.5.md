macOS can now open images from Finder. Double-clicking a picture, using *Open With > zimged*, or
`open -a zimged photo.png` opens it, where every build since v0.1.0 refused with "zimged cannot
open files in the 'PNG image' format". Linux and Windows are unchanged.

## macOS

- Finder delivers a file you open through a `kAEOpenDocuments` Apple Event rather than on the
  command line, and zimged only read the command line, so the file never reached it and macOS
  showed its own rejection dialog. zimged now listens for that event and opens the file, whether it
  launches the app or hands the file to an already-running copy. Clicking the Dock icon raises the
  window. As with a multi-file drop, opening several files at once shows the first.
