lecoq can now file the image you're looking at straight into another folder, without leaving the
viewer. Copy it or move it, from the menu, a shortcut or a right-click. This makes lecoq useful for
sorting a folder of images, not just looking through it.

## Copy and move the file

- **Copy to…** (Alt+C) puts a copy of the open image's file into a folder you choose. **Move to…**
  (Alt+M) sends the file there instead. Both open your system's own folder chooser.
- They live in the File menu beside **Move to trash**: all three act on the file as a whole.
- By default you stay where you were, so you can keep sorting. After a move, the next image in the
  folder appears, exactly as it does after sending one to the trash; after a copy, the same image
  stays on screen. Turn on **View › Follow files after copy/move** to have the window follow the
  file to its new folder instead. That choice is remembered between runs.
- lecoq never overwrites: if a file of the same name is already in the target folder, nothing
  happens and the status bar says so. Moving a file to another drive works too.
- If the image has unsaved edits, lecoq asks to save them first, so your annotations go with the
  file you copy or move.

## A right-click menu

- Right-click the image, when no tool is active and nothing is selected, to open a menu with
  **Copy**, **Paste**, **Copy to…**, **Move to…** and **Move to trash** — the everyday actions,
  right where the pointer already is.
- Right-clicking while a drawing tool is active still just switches back to Select, as before.

## Also

- The Edit menu's **Delete** now applies only to selected annotations. Sending the file to the
  trash still lives in the File menu and on the Delete key when nothing is selected, as it always
  has.
