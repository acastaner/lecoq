zimged is now **lecoq**: *Lire, Éditer, Capturer, Orner et Quadriller*. Le Coq, the rooster. The
viewer and editor are unchanged; only the name is new, along with the binary, the packages and the
app ID (`io.github.acastaner.lecoq`). The repository moved to
[acastaner/lecoq](https://github.com/acastaner/lecoq); the old links redirect.

## Upgrading from zimged

- Your settings carry over. On its first launch lecoq copies `zimged/config.toml` into its own
  config folder. The old file is left where it was.
- The `.deb`, `.rpm` and AUR packages replace the zimged package. The Windows installer upgrades
  over an installed zimged.
- The Flatpak is a new app ID, so it installs next to the zimged Flatpak, and its settings start
  from the defaults. Uninstall `io.github.acastaner.zimged` yourself.
- The winget package is now `acastaner.lecoq`.
- lecoq can't hand an image to a zimged window that is still open, or the reverse. Close zimged
  before you start using lecoq.
