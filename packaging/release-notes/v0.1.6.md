macOS really opens images from Finder now. v0.1.5 still refused a double-clicked image with
"zimged cannot open files in the 'PNG image' format" whenever that double-click was what launched
zimged. Linux and Windows are unchanged.

## macOS

- Double-clicking an image, *Open With > zimged* or `open -a zimged photo.png` opens the image when
  zimged is not yet running. v0.1.5 started listening for Finder's request too late in its launch,
  after macOS had already handed the file to its default handler, which refused it. zimged now
  listens from the start of its launch. Opening a file while zimged is already running works as it
  did in v0.1.5.
