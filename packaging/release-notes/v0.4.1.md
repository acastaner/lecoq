This release changes nothing about how lecoq looks or what it does. It is an under-the-hood
tidy-up that keeps the app easy to change safely as it grows. Everything you open, save, copy,
move or annotate behaves exactly as it did in 0.4.0.

## What changed

- **Consolidated code.** Scattered, duplicated and redundant code was gathered into one place, so
  it stays consistent and is safer to change.
- **Single sources of truth.** Things that used to be written out in several parallel places are
  now declared once, removing a class of "kept-in-step by hand" bugs.
- **Better-tested internals.** Core drawing code gained direct tests it previously lacked.

No new features, no changed shortcuts, no change to behaviour, speed or files.
