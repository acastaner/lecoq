This release sharpens the file-sorting workflow added in 0.2.0 and adds a quicker way to move
around a folder.

## Pick up where you left off

- lecoq now remembers the folder you last used for **Copy to…** or **Move to…**, even after you
  quit and reopen it. The next time you copy or move, the folder chooser opens right there, so
  sorting images into the same place across sessions takes one step instead of navigating back
  every time.
- Both operations share the one remembered folder, and it only changes when you actually pick a
  folder — cancelling the chooser leaves it alone. If the remembered folder has since been deleted
  or unplugged, lecoq quietly falls back to the current image's own folder.

## A warning you can't miss when a copy or move can't be done

- When a **Copy to…** or **Move to…** doesn't put the file where you asked, lecoq now tells you
  with a popup you dismiss, instead of a line in the status bar that was easy to miss. This covers
  a genuine error (for example a full disk or a folder you can't write to), a file of the same name
  already being in the target folder, and trying to move a file into the folder it's already in.
- Successful copies and moves stay quiet, exactly as before.
- The uncommon case of moving a file to another drive where the copy succeeds but the original
  can't be removed now says exactly that — a copy was made, the original is still there — instead
  of simply reporting that the move failed.

## Jump to the first or last image

- Press **Home** to jump to the first image in the folder and **End** to jump to the last,
  alongside the arrow keys (and the mouse wheel) for the next and previous image. At the first or
  last image — or in a folder with a single image — they do nothing. They're listed with the other
  keyboard shortcuts under Help.
