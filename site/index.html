Double-click an image. It’s already open.

lecoq is a small image viewer and quick editor. Flip through the folder with the wheel, mark an image up with arrows, text and blur, then save or copy it.

Download lecoq v0.1.7 Linux, Windows and macOS
107 ms from launch to first image

Cold start at p50 on an Intel Core i5-12600KF under Wayland. The budget is 150 ms at p90.

A viewer that keeps up with you

  • The wheel or ← → moves through the folder, in the same order as your file manager.
  • Ctrl+wheel zooms, 0 fits the window, F11 goes fullscreen.
  • Delete sends the file to the trash and shows the next one.
  • JPEG, PNG, WebP, GIF, BMP, ICO, TIFF and AVIF. Animated GIF and WebP play.

Mark it up without opening an editor

Every tool is one key, the same ones Greenshot uses. Annotations stay editable until you leave the image, and highlight and blur show exactly what will be saved.

  • RRectangle
  • EEllipse
  • LLine
  • AArrow
  • FFreehand
  • TText
  • IStep counter
  • HHighlight
  • OBlur
  • CCrop

Save it, or paste it straight into the chat

  • Ctrl+S saves in place and keeps EXIF and the colour profile. Save As writes PNG, JPEG or WebP.
  • Ctrl+C copies the whole image, ready to paste anywhere.
  • Ctrl+V drops a clipboard image on top, or opens it in an empty window.
  • One undo history covers everything, and saving doesn’t clear it.
